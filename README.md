# doublethink_interventions

Studies are organized by number in folders. 

In each folder, the .Rmd file is the RMarkdown file that can be used to reproduce the analysis. 
The datasets with the extensions _raw are the raw databases containing all participants before cleaning. 
The datasets with the extensions _filtered are the datasets after preregistered data cleaning. 
The datasets with the extensions _final are the final datasets after cleaning and data calculations.
